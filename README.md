# 정수의 서재 · 지식 라이브러리

관계, 사랑, 시간과 성장에 관한 책을 의미 있는 지식으로 압축한 한국어 라이브러리입니다. 왼쪽에서 책과 주제를 선택하고 오른쪽에서 핵심 지식, 판단 기준, 기억할 문장과 실천 질문을 읽습니다. 원본 파일은 저장하거나 배포하지 않습니다.

**[실행 방법·기능·자료 구조 → README.library.md](README.library.md)**

```sh
npm test
npm run build
npm start
```

브라우저로 `http://127.0.0.1:4173`을 열거나, 생성된 `dist/library.html`을 직접 열어 사용할 수 있습니다. 외부 패키지 설치가 필요하지 않습니다.
